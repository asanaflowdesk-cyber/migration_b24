# Регистрация пользователей из Google Sheets

Workflow `20 | Пользователи — регистрация из Google Sheets` использует книгу `ГПО Недра`.

Входной лист `new_users_add`:

```text
NEW_id | Филиал | Ф.И.О | Должность | электронный адрес | внутренний номер | мобильный +
```

- `Филиал` — числовой ID подразделения Bitrix24;
- `NEW_id` может быть пустым до регистрации;
- `dry_run` проверяет строки, подразделения, email, ФИО и дубли без записи;
- `apply` создаёт пользователя, записывает его ID в `NEW_id`, затем по ФИО заполняет в `user_list` поля `user_id`, `DepartmentID` и `name`;
- если пользователь с таким email уже существует, новый пользователь не создаётся, а найденный ID записывается в таблицы;
- при повторном запуске заполненный `NEW_id` сверяется с Bitrix24 и email.

Для чтения и записи нужен GitHub secret `GOOGLE_SERVICE_ACCOUNT_JSON` с полным JSON сервисного аккаунта Google. Книга должна быть предоставлена email этого сервисного аккаунта с правом редактора. Без этого секрета `apply` останавливается до создания пользователей.

Боевой запуск требует подтверждение `REGISTER_USERS`.
