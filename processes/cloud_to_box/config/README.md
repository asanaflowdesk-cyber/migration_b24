# Конфигурация миграции

## migration.json

Содержит:

- соответствия стадий облака стадиям лидов и сделок коробки;
- правило `LOSE → JUNK`;
- исключение четырех исходных лидов;
- поле страхового продукта `UF_CRM_1785917145255`;
- соответствия заполненных пользовательских полей;
- папку и максимальный размер файлов.

Изменять коды стадий и полей можно только после проверки потоком 10.

## users.csv

Ручные соответствия используются раньше автоматического поиска по email и ФИО.

```csv
source_user_id,target_user_id,comment
1,25,пример ручного соответствия
```

Не нужно добавлять строки для пользователей, которые однозначно находятся автоматически.
