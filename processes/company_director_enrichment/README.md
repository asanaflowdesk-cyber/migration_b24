# 35 — Обогащение компаний без руководителя

Назначение: найти в Bitrix24 компании, для которых не определён руководитель, получить ФИО руководителя из открытых справочников по точному БИН и безопасно дополнить CRM.

## Источники

Поток использует только общедоступные страницы без авторизации и без обхода CAPTCHA/ограничений:

1. Adata — `https://pk.adata.kz/counterparty/main/company/<БИН>/basic-info`
2. Kompra — `https://kompra.kz/organization/<БИН>`
3. Бизнес Аналитик — публичная карточка `ba.prg.kz`; канонический URL ищется через публичную sitemap. Если sitemap не дала URL, выполняется безопасная попытка стандартной BIN-ссылки.

На каждой странице обязательно проверяется точное совпадение БИН. ФИО принимается только из блока руководителя и только если оно похоже на полное имя из 2–4 слов.

Если два источника показывают разные ФИО, третий источник используется как арбитр. При отсутствии большинства пакет получает `source_conflict` и в Bitrix не записывается.

## Какие компании считаются кандидатами

Компания попадает в поиск, если одновременно:

- в реквизитах нет корректного `RQ_DIRECTOR`;
- нет связанного контакта с признаком руководителя/директора/учредителя или маркером `EQAZYNA_DIRECTOR:`;
- найден один однозначный 12-значный БИН в `RQ_INN` либо `ORIGIN_ID`.

Компании с уже известным руководителем не трогаются. Компании без БИН или с конфликтующими БИН попадают в лист `Пропуски`.

## Что делает apply

Перед каждой записью процесс заново читает компанию, реквизиты и контакты из Bitrix24.

Если руководитель появился после начала запуска, запись не выполняется. Если БИН изменился, запись не выполняется.

Для найденного руководителя:

- создаётся контакт `Руководитель`, связанный с компанией, с тем же `ASSIGNED_BY_ID`, что у компании;
- если контакт с тем же ФИО уже существует и его ответственный совпадает с компанией, он не дублируется: к нему добавляется маркер руководителя;
- если такой контакт уже закреплён за другим ответственным, пакет блокируется как `matching_contact_owner_conflict`;
- пустое `RQ_DIRECTOR` в реквизитах компании заполняется найденным ФИО;
- после записи контакт и реквизиты перечитываются и проверяются.

Поток не меняет ответственных компаний и лидов. Для выравнивания ответственных после обогащения используется workflow `31 | Синхронизация ответственных — руководитель → компании и лиды`.

## Режимы

`dry_run` — только поиск и отчёт, Bitrix24 не изменяется.

`apply` — запись в Bitrix24. Требуется подтверждение:

```text
ENRICH_MISSING_DIRECTORS
```

## Результаты

В артефакт `35-company-director-enrichment-*` входят:

- `company_director_enrichment.xlsx` — найденные руководители, источники, ссылки и результат;
- `company_director_enrichment.json` — подробный машинный отчёт;
- `company_director_enrichment_summary.json` — краткая сводка.
