# Сверка ответственных: руководитель → компания → лиды

Workflow: `31 | Рассинхрон по руководителям`.

Источник истины для назначения — ответственный контакта руководителя.
Один руководитель может быть связан с несколькими компаниями, у каждой компании может быть несколько лидов.

Правило сканирования:

1. Загружаются компании, лиды и контакты, отмеченные как руководители (`POST` содержит `Руководитель` или есть метка `EQAZYNA_DIRECTOR`).
2. Контакты одного руководителя объединяются по нормализованному ФИО, поэтому один человек с несколькими компаниями показывается одним деревом.
3. Для руководителя историческим ответственным считается самый ранний его контакт с заполненным `ASSIGNED_BY_ID`.
4. Под руководителем выводятся все его компании, под каждой компанией — все связанные лиды.
5. В отчет попадают только деревья, где есть рассинхрон: ответственный компании или хотя бы одного лида отличается от ответственного руководителя; также попадают случаи, когда карточки одного руководителя сами имеют разных ответственных.
6. Видимый Excel содержит только шесть колонок: `Руководитель`, `Ответственный руководителя`, `Компания`, `Ответственный компании`, `Лид`, `Ответственный лида`.
7. В `apply` меняется только ответственный компании и только на ответственного руководителя. Контакты руководителей и лиды workflow не изменяет.
8. Если у компании среди лидов 3+ разных ответственных, компания автоматически не меняется и остается для ручного разбора.
9. Если у руководителя нет ответственного, автоматического изменения нет.

Файл результата:

- `company_owner_desync.xlsx` — дерево рассинхрона.
- `company_owner_sync_summary.json` — техническая сводка для лога workflow, в Artifact не выгружается.

Для боевого запуска workflow требует режим `apply` и подтверждение `SYNC_COMPANY_OWNERS`.
