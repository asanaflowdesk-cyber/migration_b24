# Сверка ответственных компаний по первому лиду

Workflow: `31 | Компании — ответственный по первому лиду`.

Правило:

1. Читаются все компании и все лиды, связанные через `COMPANY_ID`.
2. Для каждой компании выбирается самый ранний связанный лид по `DATE_CREATE`; при одинаковой дате — по меньшему `ID`.
3. Если `ASSIGNED_BY_ID` компании отличается от `ASSIGNED_BY_ID` первого лида, компания попадает в список исправления.
4. В `dry_run` записи в Bitrix24 нет.
5. Компании с 3+ разными ответственными по связанным лидам автоматически не меняются: они выводятся отдельно для ручного решения.
6. В `apply` меняется только `ASSIGNED_BY_ID` остальных компаний. Лиды, контакты и сделки не изменяются.
6. Если у первого лида нет ответственного, компания не изменяется.
7. Компании, у которых среди связанных лидов три и более разных ответственных, выводятся отдельно независимо от необходимости переназначения компании.

Файлы результата:

- `company_owner_sync.xlsx` — три листа: несовпадения, 3+ ответственных, все компании со связанными лидами;
- `company_owner_mismatches.csv` — только компании, где ответственный компании не совпадает с первым лидом;
- `company_lead_owner_spread_3plus.csv` — компании с 3+ разными ответственными по лидам;
- `company_owner_audit.csv` — полный аудит компаний со связанными лидами;
- `company_owner_sync_summary.json` — сводные количества.

Для боевого запуска workflow требует режим `apply` и подтверждение `SYNC_COMPANY_OWNERS`.
