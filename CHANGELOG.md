# Changelog

## v5 — постоянный парсер e-Qazyna в том же self-hosted репозитории

- добавлен отдельный процесс `processes/eqazyna_leads`;
- добавлен workflow `30 | e-Qazyna — ГПО в лиды`;
- workflow переведен на `cmd`, как остальные потоки этого Windows runner;
- используется существующий secret `TARGET_BITRIX_WEBHOOK_URL`;
- добавлены режимы `dry_run` и `apply` с обязательным подтверждением боевого запуска;
- парсер создаёт и обновляет только лиды, один основной лид на один БИН;
- поле `UF_CRM_1785917145255` заполняется значением `ГПО недропользователя`;
- при обновлении сохраняются текущая стадия и ответственный;
- добавлено распознавание лидов, перенесённых из облака со старыми маркерами `EQAZYNA / eQazyna|номер|БИН`;
- выбранный старый лид переводится на постоянный маркер `EQAZYNA_LEAD / БИН`, чтобы последующие запуски не создавали новый дубль;
- добавлены журналы Excel/JSON и автономные тесты парсера;
- автоматическое расписание не включено.
