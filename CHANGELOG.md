# Изменения версии 3.0

- Исправлено бесконечное повторение метода `methods`.
- Добавлена защита от одинаковых страниц и зацикливания пагинации.
- Добавлены подробные счётчики прогресса в GitHub Actions.
- Добавлен экспорт всех типов CRM-справочников и всех статусов.
- Добавлен отдельный справочник статусов задач и расшифровка `STATUS_NAME` в выгрузке задач.
- Добавлен полный реестр конфигурации пользовательских полей CRM.
- Добавлены отдельные реестры пользовательских полей по сущностям.
- Сырые REST-ответы отключены по умолчанию для ускорения.
- JSON-наборы записываются компактно.
- Таймаут workflow увеличен до 180 минут.
- Artifact загружается даже после ошибки, если выходные файлы успели сформироваться.
- Удалён пустой workflow `main.yml`.
- Из `.env.example` удалён реальный webhook.
- Добавлены тесты защиты пагинации.
