# События назначения элементов пакета

Vercel-обработчик принимает `ADD` и `UPDATE` для контактов, компаний и лидов.
Он сохраняет порядок смены ответственных в журнале `OWNER_EVENTS` Google-очереди.
Для контактов сохраняется также обычная очередь пакетной синхронизации.
Обработку выполняет постоянный worker 31A; запуск GitHub Action на каждое
событие не требуется.

## Серверные переменные

- `PUBLIC_BASE_URL` — адрес проекта обработчика.
- `BITRIX_WEBHOOK_KEY` — секретный ключ обработчика длиной не менее 32 символов.
- `BITRIX_ALLOWED_DOMAIN` — домен портала без протокола.
- `GOOGLE_QUEUE_URL` — `/exec` URL опубликованной Google Apps Script очереди.
- `GOOGLE_QUEUE_KEY` — значение `QUEUE_API_KEY` из свойств Apps Script.
- `TARGET_BITRIX_WEBHOOK_URL` — серверный входящий вебхук для чтения карточек.
  Используется, если событие Б24 не содержит OAuth-токен. Для надёжного чтения
  назначений от роботов рекомендуется задать его; в клиентский HTML он не попадает.

## Установка

Путь обработчика локального приложения: `/api/bitrix/app`.
Страница установки: `/api/bitrix/install`.

В приложении требуется доступ CRM. После публикации новых исходников повторно
открыть страницу установки в Б24: она зарегистрирует `ONCRMCONTACTADD`,
`ONCRMCONTACTUPDATE`, `ONCRMCOMPANYADD`, `ONCRMCOMPANYUPDATE`, `ONCRMLEADADD`
и `ONCRMLEADUPDATE` на один обработчик. Повторная установка перепривязывает
только этот URL и не удаляет обработчики других приложений.

Первый сотрудник любого элемента технического пакета фиксируется worker до
переноса карточек. Более поздний лид или контакт с другим сотрудником не меняет
закрепление. Полная инструкция обновления очереди и worker:
`processes/company_owner_sync/README.md`.

Если ответственного прочитать не удалось, событие сохраняется с неизвестным
владельцем и запускает сверку. Из нескольких уже разных сотрудников без
достоверной истории первый не угадывается.

Формат стандартного события Б24 содержит ID карточки, а не старое и новое
значение ответственного. Описание: https://apidocs.bitrix24.com/api-reference/crm/leads/events/on-crm-lead-update.html
