# DeskFlow для коробочного Битрикс24

**Если вы настраиваете бота**, начните с раздела ниже. **Если вы устанавливаете сборку**, откройте [УСТАНОВКА.md](УСТАНОВКА.md).

## Как работать с конструктором

1. Откройте личный диалог с DeskFlow и отправьте `SOS`. Кнопку **«Управление DeskFlow»** увидят владелец и редакторы, которых он добавил.
2. На вкладке **«Сценарий»** откройте нужную карточку. Начальный сценарий содержит 102 окна, включая меню, дерево запросов, инструкции, каталог страховых продуктов и анкеты инициатив.
3. В карточке измените сообщение, подсказку, видимость окна и допустимый ответ. Можно принимать текст, вложения или выбор кнопками. Для вложений задаются количество, размер и расширения файлов. Для нескольких вариантов можно установить минимум и максимум, а для «Другое» запросить уточнение.
4. Настройте кнопки. Можно выбрать текст, цвет, порядок и действие. Например, открыть следующее окно, вернуться к предыдущему, открыть ссылку, скачать файл с Диска Б24, создать задачу, сохранить черновик, завершить ветку или отменить обращение. Карточки и стрелки на схеме можно перетаскивать. Полный список переходов доступен в настройках окна. Правила проверяются сверху вниз. Если совпадений нет, используется переход «Иначе». Для скрытых окон предусмотрен свой переход.
5. На вкладке **«Поля задачи»** задайте, какие ответы попадут в задачу Б24. Эта настройка доступна владельцу и редакторам. Сотрудник отвечает на вопросы в чате. В одно поле можно вставить несколько ответов и свой текст. Для этого выберите поле, затем используйте кнопку «Вставить ответ».

   ```text
   Тип обращения — {{request_type}}
   Суть — {{description}}
   ```

   Поддерживаются название, описание, срок, приоритет, ответственный, проект и одиночные текстовые поля задачи, доступные сервисной учётной записи. Для срока, заданного только датой, используется конец дня по времени Алматы. Если для шаблона отмечена обязательность, нужно заполнить каждый указанный в нём ответ.
6. Откройте **«Проверка диалога»** и пройдите сценарий с пробными ответами. После отправки видны рассчитанные поля будущей задачи. Файл в предпросмотре служит примером, а создание задачи симулируется.
7. Нажмите **«Сохранить и применить»**. Редактор проверит настройки и сразу запишет новую версию для новых обращений. Git, выкладка кода и перезапуск бота для изменения сценария не нужны. Начатые обращения и сохранённые черновики продолжаются по своей версии. Вкладка **«Версии»** позволяет применить прежнюю версию. Кнопка «Сохранить черновик» сохраняет рабочие правки в редакторе.

### Черновики, вложения и журнал

Сотрудник может вернуться к своему сохранённому черновику и проверить ответы перед созданием задачи. При смене ветки бот сохраняет подходящие ответы и файлы. Вкладка **«Обращения»** показывает окна, нажатия, сообщения и сведения о вложениях. Ответы остаются в журнале, даже если задача ещё не создана. Сами файлы хранятся на Диске Б24.

Для кнопки скачивания используйте путь скачивания с Диска, который открывается у сотрудника под его собственной сессией Б24. Право на файл проверяет Диск. Запись в журнале означает, что сотрудник открыл ссылку на скачивание.

При подтверждении бот сохраняет ответы до запроса в Б24. Если ответ от портала потерялся, кнопка **«Проверить наличие задачи»** ищет исходную задачу по идентификатору обращения. Повторная отправка предлагается после явного отказа. Обращения с неопределённым результатом остаются в журнале для сверки.

### Доступ

Права выдаёт и отзывает владелец на вкладке **«Доступ»** по числовому ID из профиля Б24. Редакторы видят конструктор, настройки полей, версии и журнал. Пересланная ссылка обычному сотруднику доступа не даёт.
