# Проверка DeskFlow

Из распакованного каталога `DeskFlow` запустите автоматические тесты. Для теста редактора нужен Node.js 18 или новее.

```sh
python -m unittest discover -s processes/flowdesk_chatbot -p 'test_*.py' -q
python -m qa.check_ui
```

В комплекте 117 Python-тестов. Они проверяют перенос веток, каталог, переходы, анкеты, черновики, шаблоны задачи, защиту ссылок и повторные нажатия. Тест редактора использует локальный имитатор авторизованного портала. В нём проверяются экран конструктора, сохранение и применение, предпросмотр полей, откат и права.

## Проверка на тестовом Б24

| Что сделать | Ожидаемый результат |
| --- | --- |
| Войти владельцем и обычным сотрудником, отправить `SOS` | Кнопка «Управление DeskFlow» появляется у владельца в личном диалоге. |
| Открыть пересланную ссылку на страницу и адрес запроса к полям задачи от сотрудника | Оба запроса закрыты. После выдачи права редактор открывается, после отзыва снова закрыт. |
| Изменить приветствие и цвет кнопки, нажать «Сохранить и применить» | Новое обращение видит правки. Начатое ранее обращение продолжает свою версию. |
| Открыть ветки с текстом, выбором, скрытыми окнами и вложениями | Поле ввода и переходы соответствуют настройкам. «Назад» ведёт к показанному окну. |
| Открыть кнопку скачивания под сотрудником с доступом к файлу и без него | Файл получает только сотрудник, которому открыт доступ на Диске. |
| Пройти тестовое обращение с файлом и дважды нажать отправку | В Б24 одна задача, вложение открывается, поля совпадают с предпросмотром. В журнале виден результат. |
| Сохранить черновик, начать новое обращение, затем возобновить черновик | Ответы, файлы и прежняя версия доступны. |
| Вернуть предыдущую версию и открыть новое обращение | Бот использует восстановленный сценарий. |

Локальная среда не содержит экземпляр вашей коробки. Проверьте PHP, фактические права REST и отображение кнопок на тестовом Б24 до рабочего включения.
